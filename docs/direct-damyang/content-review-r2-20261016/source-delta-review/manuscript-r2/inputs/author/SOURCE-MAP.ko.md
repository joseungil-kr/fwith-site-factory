# 근거와 공개 경계

직접 확인: 보관된 원본 문서·상품 HTML·정책 이미지·정부 식별 자료를 읽고 최종 연구 검토 SHA와 manifest SHA를 대조했다. 네 상품사진과 승인 배너 3개의 실제 바이트를 재사용했다. 원고의 주장 연결은 SOURCE-MAP.json에 있다.

도구 보고: 원격 HTTP200·정부자료 재취득·GitHub 현재 main 대조는 연구 단계의 보관된 결과다. 이번 집필 단계에서 새 원격 검사를 했다고 주장하지 않는다.

추정·판단: 실질 홈 하나에 선택·가격·배송비·리본·변경 조건을 모으는 편집안이다. 시설 상세를 만들 근거가 부족해 세 시설 상세를 보류했다. 복제 여부와 어투는 별도 독립 검토를 받아야 한다.

미확인: 실제 renderer·빌드·DOM·브라우저·공개 HTTP·hostname 소유권·배송·재고·환불·사진 전송·색인·순위. 원문 연구 폴더, 내부 지침, 로그나 경쟁사 본문은 고객 사이트로 발행하지 않는다.

## r2 정책 후속 확인

추가 원본 이미지 4개의 SHA256을 다시 계산하고 B201·B203·B205 상단·하단 및 B060 하단 조건을 직접 읽었다. 기존 165/24/16/3개 원문 분모와 null 점수는 그대로 두고 상단 6개 조항, 적용범위 미확정 후속사실 1개를 별도 기록했다. 기존 M09는 하단 게시 관찰이지 전체 조건의 완결된 요약이 아니다. 원본 이미지와 과거 검수는 공개 정적 산출물에 포함하지 않는다. r2 실제 빌드·화면·공개 응답은 미검증이다.
