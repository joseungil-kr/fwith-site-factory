# 담양군 구매 홈페이지 집필 설계

실질 홈페이지 / 한 곳에서 사진 4종, 기본가격, 담양 게시 추가배송비 10,000원, 합산 참고예산을 바로 비교하는 의도다. 사진을 보러 존재하지 않는 시설 상세로 이동시키지 않는다. 메타 제목의 사진·가격·배송비와 첫 답변이 같은 의도를 다룬다.

리본 문구와 보낼 곳, 희망일정을 설명하고 주문정보를 한 곳에 묶었다. 시설은 2026년 4월 1일 명부의 3개 식별 정보를 간결히 제시한다. 운영자 원본과 현장 조건을 확보하지 못했으므로 시설 상세 0개, 빈 목록 0개다. 시설 상태를 만들거나 납품처 목록으로 포장하지 않는다.

본문은 새로 집필했다. 필수 사실·공통 자산을 제외한 문장 중복은 body-count-and-overlap.json에 기록하며, 낮은 중복 수치도 독립 편집 검토를 대체하지 않는다. 상품 기본가+추가배송비는 참고 계산이고 finalPriceKRW는 모두 null이다. B201·B203·B205의 상단 평일 19시 이후/주말·공휴일 19시 이후 조건과 하단 주말·공휴일 제외 조건을 게시 위치별로 함께 유지하고, 적용범위·예외 관계를 확정하지 않았다. B060의 별도 21시 조건도 유지했다. 제작 완료/출고 취소 정책은 둘 다 남겨 자의적 우선순위를 만들지 않았다.

홈의 상품사진 4장과 배너 3장은 분리된 역할로 표시한다. message 이후 상품·가격, budget 이후 리본·시설·주문·FAQ, consultation 이후 상담과 출처로 배치한다. FAQ 네 개를 펼친 상태로 표시하며 source H2는 한 개다. 내부 구매동선은 실제 홈의 fragment이고 외부 상품은 각 SKU 상세, 상담은 1844-0644다.

원고 후보만 준비했다. 홈 1개+404의 새 스키마 지원, 실제 DOM/화면·공개 HTTP·IndexNow를 검증하지 않았다. 관련 목표와 자료는 render-plan.json과 output-context-map.json에 있으며 원문·정책·현재 사실의 분모와 원래 null 점수는 original-clause-review-input.json에 보존했다. 계획된 실제 페이지 수는 2개, indexable은 1개이며 실제 산출물과 사이트맵 수는 검증 전 null이다. 전국 완료 누계는 늘리지 않는다.
