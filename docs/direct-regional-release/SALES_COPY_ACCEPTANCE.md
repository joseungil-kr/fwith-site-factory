# 꽃이랑 지역 페이지 구매·친절 품질 기준

적용 요청: 2026-10-11. 공개된 모든 지역 고객용 페이지와 새로 만드는 지역 페이지에 적용한다. 지역별 URL·글 수·원래 계획 분모·보류 글·검증된 사실을 보존한다. 현재 상품과 전달 가능 여부를 발명하지 않는다.

## 합격에 필요한 고객 관점
1. 제목과 첫 답변에서 누구에게 어떤 꽃을 왜 보내는지 즉시 이해된다. 첫 문단을 주소 확인이나 금지사항 목록으로 시작하지 않는다. 단, 실제 반입 제한으로 구매 자체가 부적절할 수 있는 시설은 그 핵심 조건을 앞에서 간단하고 친절하게 알린다.
2. 꽃을 보내는 목적과 받는 사람을 중심으로 설명한다. 축하·위로의 마음, 예산 내 선택, 첫 주문의 부담을 줄이는 상담 안내가 자연스럽게 드러난다. 근조는 과장이나 압박 없는 차분한 말투를 쓴다.
3. 상품 비교는 확인된 차이만 사용한다. 공식 상품명·현재 기본가격·실제 사진으로 예산별 선택을 돕되, 가격만으로 꽃 수량·높이·품질·수명을 발명하지 않는다. 네 상품을 설명하면 네 실제 카드가 있어야 한다.
4. 주문 안내는 필요한 정보를 적게 묶는다. 처음 주문하는 사람에게 무엇을 준비하면 되는지, 전화로 무엇을 상담할 수 있는지 친절하게 쓴다. 같은 내용을 섹션마다 되풀이하지 않는다.
5. 지역·시설 고유 정보는 실제 구매에 도움이 되는 1~3가지로 선별한다. 잘못 보내기 쉬운 건물·지점, 행사 수령 조건 등은 독자의 일을 줄이는 문장으로 설명한다. 모든 자료를 본문에 풀어놓지 않는다.
6. 불확실한 배송 일정·최종금액·현장 반입은 필요한 위치에서 짧게 안내한다. '확인하세요/보장하지 않습니다/추정하지 마세요'가 판매 설명보다 우세하면 불합격이다. 중요한 제한을 숨기거나 뒤늦게 알리는 것도 불합격이다.
7. 조사 과정, 연결 실패, 도구·검수·검색 공개문·증거 부족 등의 작업 사정은 고객용 설명에서 뺀다. 사실 확인일과 출처는 간결한 출처 영역에 남긴다. 불확실한 사실은 확정적으로 쓰지 않는다.
8. 친절함은 독자에게 의무를 나열하는 것이 아니라 선택과 주문을 쉽게 만드는 데서 확인한다. 읽고 나서 다음 행동이 명확하고 부담이 줄어야 한다.

## 보내는 마음과 구매 기대를 살리는 서술
- 결혼하는 두 분의 앞날을 축복하는 마음, 기업의 새 도약을 응원하는 마음, 임용·승진을 향한 존경과 축하, 조문에서 전하고 싶은 위로처럼 실제 상황을 자연스럽게 이야기한다. 짧은 인사와 스몰토크가 상품 선택·상담으로 부드럽게 이어지게 한다.
- 고객이 어떤 마음으로 꽃을 고르고 무엇을 기대하는지 헤아려 쓴다. 예산·취향에 맞는 선택을 돕되 지출이 클수록 정성이 크다고 압박하지 않는다.
- 지역·시설 조사는 사실 확인의 토대다. 무관한 입주기업과 호실, 장황한 주소 대조를 본문 소재로 채우지 않는다. 실제 구매에 도움이 되는 고유 사실만 간결히 남긴다.
- 체크리스트·수령 확인·금지 경고가 본문의 중심이면 불합격이다. CTA 앞뒤에서 같은 경고를 반복하지 않는다. 중요한 실제 제한은 필요한 위치에서 친절하고 짧게 알린다.
- 지역명·시설명만 바꾼 감성 문장 템플릿도 복제다. 구매 상황과 해당 페이지의 고유 맥락을 읽고 개별 서술한다.
- 친절한 판매 문구를 만들기 위해 설치·도착 보장·상품 선별·품질·실적·제휴·배송 서비스 약속을 발명하지 않는다. 실제 확인된 사업 정보와 상품 설명 범위 안에서만 쓴다.

## 권장 흐름
- 목적에 맞는 첫 답변과 상담/상품 CTA
- 실제 상품과 예산별 비교
- 그 장소에 보내는 데 도움 되는 고유 설명
- 짧은 주문 방법과 필요한 확인사항
- 공식 출처와 확인일
순서를 기계적으로 통일하지 않고 구매 의도에 맞춘다. 문자수나 섹션 수를 채우기 위해 늘리지 않는다.

## 고객을 존중하는 설명
- 고객이 주소·주차장·행사장 같은 기본 개념을 모른다거나 실수할 것이라고 가정해 훈계하지 않는다. 확인된 빈발 문제도 아닌 오주문 시나리오를 만들어 분량을 늘리지 않는다.
- 시설의 주소·건물·홀 정보는 필요한 만큼 짧게 제시한다. 주소 대조, 접수처와 수령지 구분, 명의·수량 구별을 구매 소구점처럼 장황하게 내세우지 않는다.
- 지역 고유성은 고객에게 실질적으로 도움이 될 때만 본문에 남긴다. 단순 행정·길찾기 정보는 간결한 시설 정보로 정리하며, 중요한 실제 반입·발인 조건은 숨기지 않는다.

## 즉시 불합격
- 배송시간·도착 보장·무료배송·납품실적·제휴·후기·재고·상품 우월성의 근거 없는 주장
- 시설명만 바꾼 복제, 구매와 무관한 수량/명의/리본 설명으로 분량 채우기
- 검토용 내부 사정을 고객 본문에 노출
- 실제 제한·추가비용 가능성을 지워 구매를 유도
- 기존 글 삭제·분모 축소·가짜 링크로 완료율 조작

## 독립 검토와 공개
작성자와 검토자를 구분한다. 사실/상품/기술 검사와 별도로 제목·첫답변·구매이유·비교도움·주문편의·친절함을 실제 전문으로 검토한다. 기존 PASS는 해당 revision의 사실/기술 증거이며 이 판매 품질을 자동 보증하지 않는다. 변경 원문 digest와 검토 digest를 결속한다. source 저장·원격 재조회·회귀빌드·공개 HTTP·검색 영수증까지 확인한다. 화면 QA는 기존 사용자 승인대로 별도 대기할 수 있다.

## 모든 신규 페이지의 문구·문체·어투 — 2026-10-13 사용자 추가 기준

친절함·공감대·짧고 자연스러운 스몰토크를 모든 신규 페이지의 작성과 독립 검토에 적용한다. 단순히 경고를 삭제하거나 존댓말을 붙이는 것으로 합격시키지 않는다.

- 화자는 실제 판매자다. 독자에게 읽기·고르기·확인하기 숙제를 계속 주기보다, 확인된 상담 범위 안에서 어떤 도움을 드리는지 설명한다. 제삼자의 안내서처럼 ‘안내받으세요/상담하실 수 있습니다’만 반복하지 않는다.
- 상황을 존중하는 공감은 짧고 구체적으로 쓴다. 결혼의 축하, 공연의 응원, 조문의 위로는 말투와 정보의 비중이 달라야 한다. 고객이 어떤 감정을 느꼈다고 단정하거나 가상의 기억·경험·실적을 꾸미지 않는다.
- 스몰토크는 상품 선택이나 상담으로 자연스럽게 이어질 때만 사용한다. 모든 글을 ‘떠오르나요?’, ‘특별한 순간’, ‘마음을 전해보세요’ 같은 정형적 감성 문장으로 시작하지 않는다. 근조 글에서 지나치게 밝거나 친근한 말투를 쓰지 않는다.
- 명령형 제목과 문장이 이어지면 다시 쓴다. ‘먼저 고르고 좁혀보세요’, ‘차분히 고르세요’, ‘천천히 안내받으세요’처럼 고객의 선택법을 가르치지 않는다. 실제로 필요한 입력정보는 한 곳에 짧게 묶는다.
- 확인 책임을 고객에게 반복해서 넘기지 않는다. 기본가격·추가 배송비·실제 반입 제한·전달 가능 여부는 필요한 위치에 남기고, 동일 경고를 상품·배너·FAQ마다 되풀이하지 않는다. 꽃이랑이 확인하지 못하는 현장 조건이나 철거 책임을 대신 처리한다고 약속하지 않는다.
- 친절함을 위한 서비스 발명은 금지한다. 무료배송·도착시간·설치·회수·환불·재고·제휴·품질·개인 경험을 근거 없이 약속하지 않는다. ‘도와드립니다’도 기존 사업 정보로 확인된 상품 선택·주문 상담 범위 안에서 쓴다.
- 홈페이지, 목록/카드, 상세 제목·첫 답변·본문, 상품 설명, FAQ, 버튼, 배너, 가격/배송 안내까지 실제로 보이는 모든 문구를 검토한다. 같은 접미어·명령형·감성 표현의 과도한 반복도 본다.

### 작성 예시
- 이전: ‘사진을 먼저 고르고 예산에 맞춰 좁혀보세요.’
  개선: ‘예산에 맞는 축하화환’ 또는 ‘예산을 말씀해 주시면 선택할 수 있는 상품을 안내해 드립니다.’
- 이전: ‘친구가 쑥스럽게 청첩장을 건네던 모습이 떠오르나요?’
  개선: ‘반가운 결혼 소식에 전할 축하화환을 안내합니다.’ 고객의 기억이나 성격을 꾸미지 않는다.
- 이전: ‘반입 조건과 추가비용은 주문할 때 모두 확인해 주세요.’
  개선: ‘표시가격은 상품 기본가격이며, 배송지에 따라 추가 배송비가 생길 수 있습니다. 최종금액과 배송 가능 여부는 주문 상담에서 안내해 드립니다.’ 실제 시설 반입 규칙은 해당 장소에 짧게 별도 표시한다.
- 이전: ‘처음 주문하셔도 천천히 안내받으세요.’
  개선: ‘처음 주문하시는 분도 편하게 문의해 주세요. 상품과 리본 문구를 상담해 드립니다.’

### 독립 어투 검토 증거
작성자와 별도 검토자가 최종 전문과 공통 노출 문구를 읽는다. ‘친절함/공감/스몰토크’, 가르치는 말투, 반복 지시, 부자연스러운 감정 가정, 판매자 화자, 실제 제한과 도움의 균형을 항목별로 기록한다. 원문 파일 digest와 최종 source commit SHA를 결속하며, 문구 변경 후에는 이전 PASS를 재사용하지 않는다. 기계 테스트 합격이나 문체 점수만으로 어투 검토를 대신하지 않는다.
