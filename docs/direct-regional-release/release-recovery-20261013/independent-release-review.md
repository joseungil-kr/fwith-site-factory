## Tool reports, judgment and limits

The prior baseline report documents original artifact provenance, immutable Git bindings, 267 artifact-file hashes, 53 exact dist files, and prior visual review. This review directly used the original HTML and original source, but did not reopen all baseline screenshot images, rerun a browser, compile Astro, install packages, or fetch public hosts. The existing source baseline visual assessment can only be reused after inspecting a fresh actual production artifact and proving the authorized metadata-only transform; an arbitrary synthetic fixture cannot establish that.

The standalone equivalence checker proves a byte relationship between its supplied directories. It does not prove those directories came from a particular Actions run, bind an actual run to a source commit, or itself reject all filesystem-type/manifest provenance issues. Before using its result as an actual production review, verify the fresh downloaded artifact identity, source/control revisions, complete release manifest and static inventory gate, compare against the verified original baseline, and independently inspect the generated output. Its state string alone is not proof of actual build provenance. The publication gate's exact revision/origin/all-file-hash binding remains mandatory.

The artifact checker alone is not a substitute for the native QA and byte-equivalence review. The layered path must preserve all three before issuing a production output contract.

No remote mutation, deployment, hostname attachment, DNS action, public HTTP verification, IndexNow request, or actual search indexing was performed or established by this independent review. National published counts must not advance on this report. Expected next steps are scoped leased saves with remote diff/readback, fresh build-only artifacts, independent actual-artifact review, then serial Geumcheon → Yeongdeungpo → Dongjak publication and live verification.
