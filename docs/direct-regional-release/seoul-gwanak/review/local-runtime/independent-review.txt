실패 및 재검증 기록
- 독립 mutation 첫 실행은 작성자의 최종 build가 dist를 교체하는 시점과 겹쳐 임시복사에 상세HTML이 없는 FileNotFoundError21건이 났다. 실패로그를 independent-mutations-race-failure.log로 보존한다. 이를 코드 결함 또는 PASS로 단정하지 않았으며, 동결된 dist에서 최종 재실행한 결과를 verdict에만 채택한다.
- 독립 render-checker 작성 초기에는 visible-surface 투영과 내부 metadata가 남은 runtime 객체 자체를 완전동일 비교하여2개 형상 차이를 표시했다. 실제 승인값 변화는 없고 runtime은 원본 articles/common과 정확히 동일함을 확인하여 원본-런타임 정확비교와 고객 DOM whitelist를 분리했다. 검수기 구현을 교정했으며 제품코드 수정은 없었다.
