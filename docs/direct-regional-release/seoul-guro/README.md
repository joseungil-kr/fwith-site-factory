# 서울 구로구 독립 준비

공식 순서: 강서구 11500 → 구로구 11530 → 금천구 11545. 강서 공개 승인 대기와 별개로 구로의 조사·계획·원고·검증을 준비했다. 이 기록은 구로 배포 승인이 아니다.

- 최초 동결 분모: 3개 구매 안내. 이후 보류/실패가 생겨도 분모와 URL을 줄이지 않는다.
- 최초 후보 이력: 8개. 활성 7맥락(6시설+1지역), 제이오스티엘은 동결 전 HTTPS 고객 출처 미해결로 보류.
- 법정동 10개·행정동 16개·관계 18개는 지역 목록이며 글 수나 배송 가능 보장이 아니다.
- 계획·원고 검토는 각각의 지문에만 유효하다. 실제 렌더·기술·화면·공개 검증은 별도 기록을 확인한다.

자료의 전체 공식 HTML은 조사 환경에서 열람했으며 저장소에는 URL, 원문 해시, 필요한 사실 및 독립 검토를 보존했다. 수집 로그의 로컬 절대경로나 raw/ 경로는 조사 산출물 위치이고 저장소 파일을 뜻하지 않는다. 상품과 배너는 사이트가 실제 쓰는 승인된 사진/자산 바이트를 재사용한다.

`source-evidence.json`은 증거 목록과 실패 범위, `fixed-plan.json`은 동결 계획, `independent-*-review`는 각 독립 검수다. 이전 revision과 보류 후보 이력은 제거하지 않는다. 국가 checkpoint와 강서 우선순위는 이 준비 때문에 바꾸지 않는다.

검증된 소스: `site-factory-seoul-guro-direct`의 `500d82d01c1cdaed3ebde047bb3ce056705daac1`. 103개 원격 소스 파일을 독립 기술검수 manifest와 대조했다. `source-readback.json` 및 `independent-technical-review.json`을 함께 확인한다. 계획 PASS, 원고·공통 UI PASS, 로컬 기술·정적 산출물 PASS는 각각 범위가 다르며 실제 브라우저·모바일 화면과 공개 배포는 미검증이다.
