# 나주 정적 출시 계약 검토

고객 원고는 기존 검수본 그대로이며 추가 필수 문구 수정은 0건입니다. 이 문서는 공개 또는 전체 출시 승인이 아닙니다.

- 직접 확인: 정확한 원고, 보존된 소스 69개와 오프라인 출력 18개의 바이트, HTML 4개, 114개 문구, FAQ 3쌍, 상품·전화 링크, 이미지 해시, 제목·첫 답변·카드 요약·사이트맵을 검사했습니다.
- 보존 근거: 기존 원문·상품사진·배너 픽셀·전문 문체 검수는 해시가 같아 재사용했습니다. 이전 코드 테스트 및 원격 저장 영수증을 새 실행으로 표현하지 않습니다.
- 판단: 홈과 상세는 각각 A04 100, SEO 70, 문서 GEO 100, AEO 90입니다. 점수는 공개된 검수 기준의 증거 충족도이며 검색 순위나 노출 예측값이 아닙니다.
- 미확인: 실제 배포 빌드와 산출물·제어 커밋 결속, 실제 브라우저 및 화면, 승인된 호스트 상태, 공개 응답과 실제 404, IndexNow 영수증은 이 범위에서 확인하지 않았습니다. S08·S09·S10·AEO A06은 0점 및 대기 상태입니다.

기존 소스에서 확인한 안내 페이지 유입 링크와 계층 표시 누락은 후속 소스에서 해소되었습니다. 상세에서 안내 페이지로 연결되고, 기존 승인 문구만 사용한 breadcrumb가 추가되었습니다. 원고는 바뀌지 않았으며 S05는 정적10점으로 복원했습니다. 이전 소스의 실패 판정을 새 소스에 소급하여 고치지 않습니다.

18개 계약 항목은 bounded-clause-evidence.json에, 기준과 점수 근거는 rubric.json 및 두 primary 품질 문서에 있습니다. 실제 검증자는 pending-production-evidence.json의 근거를 확보하고 같은 원고·이미지를 실제 산출물에 결속한 뒤 별도 최종 문서를 작성해야 합니다. 단순히 상태 문자열만 PASS로 바꾸면 안 됩니다.

범위는 홈과 장례식장 상세 2개 주요 페이지, 검색 제외 안내 1개, 기술적 오류 페이지 1개입니다. 안내 페이지는 자식 1개·배너 0개입니다. 핵심 허브와 전체 출시 상태는 NOT_ASSESSED입니다.

원고 본문 2,582자는 도입부와 절별 본문·목록을 공백 및 필드 사이 줄바꿈을 포함해 센 유니코드 글자 수입니다. FAQ와 마무리를 더하면 3,026자입니다. 2,500~3,000자는 원고 분량 목표이며 자동 합격·탈락 기준이 아닙니다.
