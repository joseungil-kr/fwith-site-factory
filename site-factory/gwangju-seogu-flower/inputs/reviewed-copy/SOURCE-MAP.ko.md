# 서구 고객 원고 출처와 제한

정본은 customer-copy.json, 필드별 출처 결속은 SOURCE-MAP.json이다. 연구 전체를 공개하는 패키지가 아니다.

## 직접 확인

- 국빈장례문화원의 공식 오시는길과 전화 안내, 보건복지부 2026-04-01 시설 CSV의 해당 행: 이름·회재로825·매월동601·대표전화062-606-4000만 사용
- 꽃이랑 4상품 원 HTML: SKU·정식 상품명·기본가격·개별사진/상세 URL. 시도 배송표8행에 서구 없음
- 실제 상품사진4개와 정책이미지2개: 혼합소재·후다지·수거없음·소재 차이와 하자/취소의 구별
- 공통 승인 배너3개: 동일한 SHA·바이트·1774×887·정확한 전화
- 지정main의 문서11개 Git blob, 선행연구218개 checksum 및7개핵심deliverable 재검산

## 도구 보고

검색결과·원문 HTTP 상태·GitHub 최근활동은 선행 연구의 보존된 도구 기록을 읽었다. 이 원고 작성자가 새 주문·통화·외부 GET을 실행한 것은 아니다. 실제 보존된 파일과 이미지는 직접 열었으므로 파일 내용 검토와 현재 실서비스 수행 여부를 구분한다.

## 편집 판단

예산→상품→리본→시설→주문 순서는 이 원고의 편집 선택이다. 리본 표현과○○표기는 예시이며 실제 고객정보가 아니다. 가격대 차이는 공식 기본가의 산술값으로, 품질·높이·꽃수량을 뜻하지 않는다. 같은 시설의 동의어는 한 상세에 묶었다. 경쟁업체의 당일·설치·실적·사진알림 약속은 쓰지 않았다.

## 기술 계획

홈·상세·support·404의 114개 한국어 문자열,4개Markdown,정본JSON,render-plan 및metadata가 있다. 도메인·origin은 null이며 namespace gwangju-seogu는 미확인 후보다. FAQ 노출·배너 분산·HTML·전화/상품CTA·canonical·social·robots·sitemap·공개404는 후속 구현에서 실제 출력으로 검사해야 한다.

## 미확인 및 공개 제외

최종 배송비·실제 반입/수령·도착시각·전화연결·재고·개별취소 적용은 미확인이다. 업체 관계·납품·제휴·운영시간을 주장하지 않는다. 고인/유족 실제정보·부고 홈·쿠키·전체 연구 원본은 공개 대상이 아니다. 고객 원고에 쓴 실제 사업 연락처는 시설 대표전화와 꽃이랑1844-0644뿐이다.

파일을 변경하면 customer-copy,render-plan,metadata,source-map,문자열·Markdown·검증·동결 목록의 결속을 다시 만들고 해당 revision을 독립검수해야 한다. 기존 연구 또는 형제 지역PASS를 새 원고PASS로 사용할 수 없다.
