### 상품·소재·시간·취소

[직접 확인] 네 SKU의 원문 HTML 가격/이름과 500×500 판매사진을 각각 확인했다. B201 59,000원, B203 79,000원, B205 109,000원, B060 149,000원이다. 색상·리본·상단 원형 장식 설명과 alt는 해당 사진에서 보이는 범위다. 크기·생화 비율·꽃 수량·품질·수명을 가격에서 만들어 내지 않았다. CTA는 각 SKU 공식 상세 URL이다.

정책 이미지의 최초 제공 JPG와 contact sheet는 열람용 재인코딩 파생본이다. 이 검토는 raw HTTP .body에서 bytes를 그대로 복사한 order-top2/de-change 원본과, 원본 decoded pixels에서 만든 무손실 PNG를 다시 열어 판독했다. 본 검수 폴더 evidence의 정책 PNG는 원본 crop과 픽셀 차이가 없음을 검사했다. 고객 게시자산 4개 JPG는 이 정책 파생본과 다르며 실제 -photo.body와 bytes가 동일하다.

기존 코드 재사용 검토는 사용자 저장소의 상품카드·공유배너, florella의 오래된 Astro 4 및 라이선스 미확인, astro-shopify의 MIT 원문·최근 push·Astro/Svelte/Shopify 의존성 검토를 보존한다. 정적 상담 사이트에 불필요한 cart/API를 가져오지 않고 기존 자산·구조를 재사용하는 판단은 이번 범위에 적합하다. 이는 실제 구현 완료 판단이 아니다.

## 도구 보고와 미확인 사항

[도구 보고] 기존 수집의 HTTP 200/403/400/502, GitHub fresh/closing 응답, 검색 실행 내역은 보존된 도구 기록이다. 검토자는 받은 bytes와 원문 내용을 독립 검사했지만 사이트를 다시 접속해 현재 상태를 인증하지 않았다.

[미확인] 군청·일부 제한자료 접근 실패, 플로라 403, 유한 GitHub 조회와 incomplete_results=true를 보존한다. 시설 정책·운영·반입·재고·주문 총액·실제 배송·전화·폼 동작·사진 진위는 미확인이다. 강진 원고의 정책 안내는 실제 주문 이행 검증이 아니다.

[미확인] build, generated HTML/DOM, FAQ 실제 가시성, 첫 CTA보다 앞선 알림, 상품링크 클릭 동작, 320/390/1280 화면, H1/H2/H3·canonical·robots·sitemap·404, 공개 HTTP 및 이미지 bytes는 수행하지 않았다. 원격 Git/main·배포·키/proof·IndexNow·콘텐츠 API·새 사용자 컴퓨터 작업도 수행하지 않았다.
