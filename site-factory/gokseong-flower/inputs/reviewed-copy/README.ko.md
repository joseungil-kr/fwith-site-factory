# 곡성 원고·설계 구현 전달용 투영

고객 문구는 r1 원본이며 출력 명세 3개만 별도 작성 설계 r2이다. 구현 대상은 홈 1개와 기술 404, 상품 4개, FAQ 3개, 이미지 7개이다. 102개 고객 문자열에 대한 119개 출력 위치 정의와 별도 SKU 4개를 적용한다.

판정은 원고·설계에 한정한다. 원래 r1 출력 명세의 필수 수정과 실패 판정은 independent-review-r1.json에 보존했고, effective-r2가 별도로 이를 해소한다. 원문 지침을 제거한 171/16/17/5 행 투영은 native-clause-public-projection.json이며 원래 전체 검수 해시에 연결되어 있다.

실제 소스·빌드·HTML·브라우저·공개 HTTP·게시 여부는 false/null이다. 이 파일은 구현이나 게시 권한을 부여하지 않는다. 후속 구현은 실제 8개 화면/상태, FAQ·H2/H3·링크·메타데이터·단일 sitemap·404를 별도로 검증해야 한다. 예상 CSS 가용성과 실제 화면 노출을 혼동하지 않는다.

옥과 화환 반입 조건, 배송 안내 간 적용 우선순위, 시설의 현재 운영, 최종가·재고·도착시각은 미확인이다. 기간 있는 5시설과 과거 6시설을 섞지 않는다. 참고 합계를 결제 최종가로 바꾸지 않는다.

PUBLIC-SAFE-REVIEW.json의 명시 allowlist와 MANIFEST.json의 해시를 확인한다. 전체 사적 지침/역사, 개인·계정·인증·결제 정보, 원문 전체 응답과 내부 로그는 포함하지 않았다. 상품·배너·시간 안내 이미지는 검토한 기존 byte만 포함한다. sourceArtifact는 로컬 원본 추적 식별자이며 이 투영 안에 원본 전체가 있다는 뜻이 아니다. 공개 배포나 제3자 공유는 수행되지 않았다.
