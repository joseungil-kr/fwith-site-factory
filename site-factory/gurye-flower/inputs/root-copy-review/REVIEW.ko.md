# 구례 r2 원고 독립 검토

판정: 원고 단계 수용. 공개/실제 HTML/검색성과 수용이 아니다.

작성에 참여하지 않은 root가 r1 원고 전문, display-copy 전체, FAQ/render-plan, 근거 대응 및 SALES_COPY_ACCEPTANCE 원문을 읽고 5개 수정점을 작성자에게 전달했다. 작성자가 별도 r2로 수정한 후 실제 diff와 r2 전문을 다시 읽었다. r1과 r2 봉인은 유지했다.

## 직접 확인
- r2 132파일 SHA를 재계산했고 불일치가 없다. display-copy는 r1과 동일 byte다.
- 상품 HTML 4개의 판매가격 59/79/109/149천원과 구례 추가비 20천원 표를 직접 파싱했다. 산술 합계 79/99/129/169천원은 일치하고 확정 견적으로 표시되지 않는다.
- 상품사진4장, 상단 정책3장, 하단정책4장, 공통 재료/수거 및 환불 이미지2장을 실제 열람했다. 기존 정책 crop8개와 원본 이미지 좌표의 pixel parity도 확인했다.
- 공식 CSV 전체에서 구례3행을 다시 추출해 시설명/주소/전화와 대조했다. 현재 반입조건은 미확인으로 유지한다.
- 19시 상하단의 서로 다른 안내와 B06021시 조건, 최소3시간 전 주문, 제작완료와 출고후 취소의 서로 다른 문구가 모두 보존됐다.
- FAQ3쌍이 원고와 render-plan에 정확하게 일치한다. 실제 표시 검증은 아직 하지 않았다.

## 문체 판단
첫 답변은 위로와 예산 선택을 설명하고, 짧은 공감이 리본문구 상담으로 이어진다. 허구의 납품 경험이나 고객 감정 단정은 없다. 메타/카드/버튼/주의/FAQ/404 전체를 읽었다. r1의 내부 편집방침 설명과 계산 숙제, 근거 불충분한 병원전화 대조 표현이 r2에서 해소됐다. 장례 후 처리는 판매자가 수거하지 않는 실제 경계이므로 시설 문의를 안내한 것은 불필요한 책임 떠넘기기로 판정하지 않는다. 정책 설명은 다소 길지만 필수 제한·원문 모호함을 숨기지 않기 위한 범위다.

## 검색 의도·정보 완결성 판단
구례20천원 추가비와 3시설 식별, 상품별 참고합계와 실제 사진/상품링크, 리본문구·주문준비·변경취소·FAQ를 한 구매 의도에 모은 구성은 수용한다. 작성자 구매의도 계획과 원문/경쟁 분석 기록을 읽었으나 이번 root 검수에서 경쟁 페이지 원문 전체를 별도로 재열람한 것은 아니다. 그 조사완료는 작성자 증거 보고와 구분한다. 문자수2847은 작성자 산출치이며 기계 통과선으로 쓰지 않는다. sibling 전체 의미 중복을 독립적으로 전수 측정하지 않았으며 기존 측정치 자체를 SEO 품질 증명으로 인정하지 않는다.

## 다음 필수 게이트
기존 코드·자산 재사용 구현, 실제 HTML 전체문구/FAQ·H1/H2/H3·CTA·사진/배너·모바일·canonical/robots/sitemap, 원격 저장 readback, 실제 build 및 공개 HTTP 검증은 별도 필요하다. 시설3개 별도 페이지 HOLD 유지. key 생성이나 provider 변경을 이 문서로 승인하지 않는다. source commit은 아직 없다.

## 확인 한계
원고 검수는 실제 주문/현장배송/시설현재운영/검색수집·색인·순위 성과 검증이 아니다. 이번 검수 도구는 보존된 원문 bytes를 열람했으며 새 원격 GET은 작성자가 수행한 기록이다. 최초 optional bs4 파서가 설치되어 있지 않아 실패했으나 Python 표준 HTMLParser로 동일 HTML 확인을 완료했고 별도 설치하지 않았다.
