# 북구 12300 고객 원고·렌더 계획 독립 검토

판정: 동결된 r1 원고와 렌더 계획은 구현 인계가 가능합니다. 필수 원고 수정은 없습니다. 실제 소스·빌드·HTML·브라우저·공개 검증 또는 발행 완료 판정은 아닙니다.

## [직접 확인] 확인된 결과

- 고객 정본의 한국어 문자열 115개를 모두 읽었습니다. 홈·상세·지원목록·404, 메타, 상품카드, FAQ, 버튼, 출처, 접근성 문구, 배너 alt와 footer의 재사용 문구가 포함됩니다.
- 실제 상품사진 4개, 승인된 공통 배너 3개, 판매자 정책 이미지 2개를 전체 픽셀로 열었습니다. 7개 고객 자산의 SHA·바이트·포맷·크기를 다시 검사했습니다. 상품은 B201 59,000원, B203 79,000원, B205 109,000원, B060 149,000원이며 각 버튼은 같은 SKU의 공식 상세로 연결됩니다.
- 정부 CSV를 별도로 파싱했습니다. 229번째 데이터행의 그린장례문화원 명칭, 하서로663번길 97, 062-250-4455는 보존 원본과 같습니다. 운영자 오시는길의 도로명·구·번호와 전화가 이를 뒷받침합니다. 지역 접두어의 차이는 지워서 법적 연속성을 주장하지 않았습니다.
- 장례절차 원문의 안치 후 호실 확인을 대조했습니다. 이것은 일반 장례 절차이며 현재 빈소, 외부 화환 수령, 24시간 배송의 증거가 아닙니다. 구호전 주소와 일곡 전화의 불일치는 고객 원고에서 제외했습니다.
- 원본 지침은 비어 있지 않은 비제목 행 154개입니다. README 54, 검색 25, 판매 49, 배너 26개입니다. 배너 표의 제목·구분선도 포함하는 원본 행 분모이므로 154개의 독립적 의무라고 세지 않았습니다. 원본 전체와 각 행의 digest를 보존하고 항목별 판정을 기록했습니다.
- 원고 입력의 판매자 정책 10항목과 추가로 검토 후 사용하지 않은 이미지 조건 5항목, 시설 절차 1항목을 대조했습니다. 제작 완료 교환·환불 불가와 출고 후 배송비 제외 환불을 모두 남기고 어느 조항이 우선하는지 임의로 정하지 않았습니다. 식물용 교환 규칙, 결제수단별 처리 예상일은 화환의 통일 규칙으로 확대하지 않았습니다.
- 상세 본문은 2,163자, FAQ는 605자, FAQ·마무리와 결합 개행을 포함하면 2,854자입니다. 제목·공통 상품카드·출처·메뉴·footer·CTA는 제외했습니다. 숫자를 통과 기준으로 삼지 않았습니다.
- 독립적인 바이트·파싱·사양 검사는 580건이며 실패는 0건입니다. 작성자의 1,357건 검사와 구분되며, 의미·어투 또는 실제 출력 검사를 대신하지 않습니다.

## [추정·판단] 어투와 판매 품질

문체 기준은 원고 범위에서 충족합니다. 조의의 인사를 어떻게 적을지 망설여지는 경우를 짧게 다루고 상품·리본 상담으로 이어집니다. 고객이 실제로 슬프거나 당황했다고 단정하지 않고, 가짜 추억·납품 경험을 만들지 않았습니다. 근조 상황에 맞는 차분한 말투입니다.

판매자 화자가 준비된 예산, 꽃의 모습, 리본 표현을 함께 상담한다고 설명합니다. 상담·의논이라는 동사는 자주 나오지만 불확실한 현장 업무를 해결한다고 약속하지 않고 각 문단의 구매 결정에 연결됩니다. 고객에게 읽는 법·선택법을 가르치는 제목이 없으며 주문정보는 네 항목 한곳에 모았습니다.

제품·리본·예산의 긍정적인 설명과 필요한 제한의 비중이 적절합니다. 기본가와 총액은 예산 영역에서, 반입·수령과 희망 시각은 시설 영역에서 설명합니다. 카드마다 배송비 구분을 짧게 반복하는 것은 개별 가격표의 역할이며, 같은 경고를 긴 문단으로 되풀이하는 형태가 아닙니다.

## [추정·판단] 검색 의도·정보 완결성

정보 완결성은 문체와 별도로 평가했습니다. 네 상품의 사진·기본가, 리본 예시, 전체예산, 시설 주소와 전화의 역할, 빈소와 희망일정, 묶인 주문정보, 소재·수거 및 변경·환불 질문에 답합니다. 정확한 최종배송비와 현장 수령 조건은 확인되지 않았지만, 이를 확정된 판매조건으로 주장하지 않는 상담 안내로서 필요한 질문과 다음 행동이 드러납니다.

홈은 가격·리본 상담의 입구이며 실제 네 상품사진은 연결된 그린 상세에 있습니다. 홈에 사진이 있다고 오해하게 하는 약속은 없습니다. 상세의 순서는 products → ribbon → budget → facility → order입니다. budget 배너는 facility 직전에 두며, 남구의 section 배열 순서를 그대로 가져오면 안 됩니다. FAQ 세 문답은 본문을 단순 반복하지 않고 주문 이후의 서로 다른 문제를 다룹니다.

남구 r2·서구 전문과 동구·나주·광양의 상품카드·출처를 제외한 본문을 읽고 비교했습니다. 같은 판매자의 상품과 정책은 의미상 공통적입니다. 낮은 20자 shingle 중복률이나 FAQ 순서 변경만으로 독창성을 인증하지 않습니다. 북구는 그린의 정부·운영자 주소/전화 대조와 안치 뒤 호실 확인 절차를 구매 상담의 순서에 연결하며, 기존 전문의 시설명만 바꾼 글은 아닙니다. 다만 현장 반입·배송에 관한 독자적인 경험이나 고유한 서비스 증거를 확보한 것은 아닙니다. 이 제한을 숨기지 않은 한정된 상세 원고로 판단했습니다.

독립 재계산은 양쪽 JSON에서 같은 기준으로 본문을 추출했으므로 작성자의 Markdown 비교와 일부 수치가 다릅니다. 두 방식 모두 정보용 측정이며 검색 품질의 통과 점수는 아닙니다. 전국 사이트 전체의 고유성, doorway 위험 부재, 검색 노출·순위·전환은 평가하거나 보장하지 않습니다.

## 원본·재사용·현재 기준

선행 연구 보고, 구매계획, 인계, 시설 원본 발췌, 상품 선택본문, 실제 경쟁 6페이지의 보존 본문, 재사용 자료를 읽었습니다. Astro와 Vercel Commerce의 실제 MIT 본문 및 Commerce README, 기존 서구의 package·CopyPage·ProductCards·SharedFlowerBanner 원문을 대조했습니다. 기존 정적 렌더러와 승인 자산을 재사용하는 방향이 적절하며 신규 결제·Shopify/API·계정을 추가할 필요는 없습니다. 라이선스와 upstream 고지는 실제 코드를 도입할 때 보존해야 합니다.

연결 GitHub GET으로 main 4fb255a725e3b988ef4bd7eec66032ea8c241f91과 비교 결과, 네 지침 원문을 다시 받았습니다. 원고 기준선 1d421424… 이후의 두 커밋은 남구 제어·검토·승인 바인딩 변경이며, 네 지침과 진행 집계는 변경되지 않았습니다. 네 원문을 로컬에서 다시 읽고 exact SHA 및 Git blob을 계산했습니다. 이 사실은 남구 공개 완료를 뜻하지 않습니다.

## [도구 보고] 관측의 경계

상품·시설·경쟁 페이지의 HTTP 상태와 수집 시각, 선행 연구의 재조회·검사 결과는 기존 도구 및 검토 기록입니다. 이번 검토자는 보존된 원문을 직접 읽고 해시를 대조했지만 해당 모든 사이트에 새로운 HTTP 요청을 하지 않았습니다. main과 compare 응답은 연결 도구 보고이며, 반환된 지침 bytes는 별도로 검사했습니다. 63/230 공개 수는 현재 저장소 기록이지 63곳의 새로운 공개 검사가 아닙니다.

## [미확인 및 실패]

- 북구의 정확한 배송비·총액, 현재 운영·전화 응답·재고, 실제 빈소·화환 반입과 수령, 발인 전 전달, 실제 주문·배송·환불 적용은 확인하지 않았습니다.
- 원고 사양의 FAQ 노출, 카드·CTA, H1/H2/H3, canonical·robots·sitemap·OG/Twitter, 내부 링크, 모바일·키보드·레이아웃은 실제 구현 후 검사해야 합니다. 원고에 데이터가 있다는 것만으로 화면에 표시됐다고 판단하지 않습니다.
- source commit, 실제 build/Actions/artifact, provider·hostname, 공개 HTML/자산 HTTP, 실제 missing-route 404, IndexNow 영수증과 실제 색인은 아직 없습니다. CoreHubLaunch와 FullLaunch는 NOT_ASSESSED입니다.
- GitHub의 Markdown 본문을 JSON으로 파싱한 로컬 오류가 한 번 있었습니다. 응답은 유지되어 올바른 문자열로 읽었습니다. 파일 저장에서 추가된 마지막 개행 1바이트도 최초 검사에서 검출했고, 도구 원문과 동일한 bytes로 복구한 뒤 네 파일을 재검증했습니다. 원격 작업 실패나 사용자 취소로 표현하지 않습니다.

## 검증 증거와 동결 계약

- independent-review-r1.json: 원고·어투·검색 의도의 별도 판정과 한계
- original-clause-assessment.json: 154개 원본 행, 15개 이미지 정책 조건, 시설 절차 검토
- visible-string-assessment.json: 고객 문자열 115개 전문과 개별 검토
- purchase-intent-assessment.json: 질문 → 답변 → 근거 → 다음 행동
- render-checklist.json: 실제 구현·화면·공개에서 수행할 검사
- evidence/independent-audit.json: 독립 검사 580건
- implementation-review-binding.json 및 REVIEW-MANIFEST.json: 원문·검토·사양의 exact byte 결속

모든 새 파일 바인딩의 path는 이 검토 패키지 루트 기준 상대경로입니다. 원본 author 패키지는 inputs/author에 변경 없이 보존했습니다. 그 안의 원래 상대경로는 해당 author 루트 기준이며, 공개 경로로 옮길 때에는 reviewed-input-projection.json의 명시적 바이트 동일성 매핑을 사용해야 합니다. 원본 인용의 상대링크를 새 바인딩으로 해석하거나 정본 내용을 바꾸지 않습니다.

이 패키지는 검토·소스 인계용입니다. 정책 이미지·지침 전문·연구 근거를 웹사이트 public에 통째로 복사하지 않습니다. 웹 렌더 입력은 검토된 고객 데이터, 계획과 7개 승인 자산입니다. 바인딩된 원문이나 자산이 달라지면 새 revision으로 재검토해야 하며, 닫힌 검토를 수정해 새 소스에 소급 적용하지 않습니다.
