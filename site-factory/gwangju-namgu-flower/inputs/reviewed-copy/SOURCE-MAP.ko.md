# 남구 원고의 근거와 한계

정본·렌더계획·선행연구·원본 파일의 정확한 SHA는 SOURCE-MAP.json에 결속했다. 자료를 읽었다는 사실과 실제 주문·공개 성공을 구분한다.

## [직접 확인]

- 고객 원고 전체를 작성하고 보존 원문과 대조했다. 정부 CSV의 헤더 제외 222행은 광주남문장례식장(주), 광주광역시 남구 서문대로499번길 26-15(송하동), 062-675-5000이다. 고객 시설정보는 이 세 가지와 자료 기준일에 한정했다.
- nammoon.kr 오시는길 발췌는 시설명·대표전화가 일치하지만, 고객용 출처나 주소 근거로 채택하지 않았다. 절차 발췌에 삼성서울병원 이름과 24시간 문구가 남은 사실을 읽었고 모두 제외했다. 지번·영업시간·운구시간도 고객 원고에 넣지 않았다.
- 공식 상품의 보존 selected HTML에서 네 SKU 이름·기본가·배송비 표를 읽었다. 남구 배송비 행은 없으며 최종 배송비와 총액은 미정으로 남겼다.
- 실제 500×500 상품사진 4개, 소재·환불 정책이미지 2개와 승인된 배너 3개를 직접 열었다. 색·배치만 설명하며 크기·수량·품종·품질 우위를 만들지 않았다. 사용한 이미지 7개는 서구 자산과 이번 연구 다운로드에 각각 바이트 일치한다.
- 최신 main 0cf99bd8a493040d2c35ce56d2027e932608374e의 README/SEARCH_CONTENT_STRATEGY/SALES_COPY_ACCEPTANCE/SHARED_BANNER_STANDARD를 새로 읽고 Git blob SHA와 연구 입력 바이트 일치를 확인했다.
- 경쟁사 5곳의 보존 선택본문, Google의 관련 원문 문단, 복원된 Naver 본문을 읽었다. 해당 업체의 서비스 약속이나 검색 성과는 확인하지 않았다.

## [도구 보고]

- 연구 수집 기록의 URL·HTTP·시각·전체 응답 SHA는 도구의 당시 관찰이다. 이 작성자는 상품·시설 페이지에 새 HTTP 요청을 하지 않았다.
- 최소화로 삭제된 전체 원문의 SHA는 현재 다시 계산할 수 없다. 직접 검사한 것은 보존된 selected HTML·시설 발췌·CSV·이미지다.
- 선행 연구의 독립검토는 연구 범위에 한정한다. 새 고객 원고의 의미·어투·정보 완결성 판정으로 재사용하지 않는다.
- 저장소의 62/230 기록은 스냅샷이다. 서구의 후속 공개는 부모 담당자가 별도로 진행하며, 이 작성자가 62개 사이트를 동시에 다시 확인한 것이 아니다.

## [추정·판단]

사진별 선택을 앞에 두고 전체예산과 리본 상담으로 이어지는 구성이 이번 남문 구매 결정에 도움이 된다는 편집안이다. 시설의 주소와 대표전화는 짧게 묶고, 동일한 반입·일정 경고를 섹션마다 반복하지 않았다. 리본문구·가상 이름은 선택 예시이며 특정 관계·종교·현장사례가 아니다.

## [미확인]

정부 등재 도메인과 nammoon.kr의 연결, 도로명·지번 일치, 현재 영업·재고·전화응답·빈소상태·꽃 반입·수령·실제 전달·최종비용·개별 환불 적용은 미확인이다. 새 원고의 독립검토, 앱 구현, source commit, 실제 build/HTML/browser/public HTTP 및 IndexNow·색인·순위도 이 묶음에서는 확인하지 않았다.

## 다음 단계

원문 규정과 전체 고객 문자열에 대한 독립 검토가 먼저다. original-clause-review-input.json은 원문 파일·행과 정책이미지 영역을 연결하며, 원문 대신 사용할 축약 합격표가 아니다. 이후 구현·출력·공개 검증에서 최종 원고 digest와 실제 source/build 결과를 다시 결속해야 한다. 계획상 canonical·sitemap·FAQ·버튼이 존재한다는 사실만으로 실제 출력 검사를 완료 처리하지 않는다.

홈에는 상품사진 카드가 없으므로 홈의 제목·도입·선택 문단을 예산과 리본 상담 중심으로 수정했다. 실제 상품사진 4개는 남문 상세에서 볼 수 있음을 명시한다. 사실과 이미지 근거, 상세 원고의 사진 비교는 바꾸지 않았다. 이 수정의 독립 승인 여부는 새 검토 결과로 판단한다.
