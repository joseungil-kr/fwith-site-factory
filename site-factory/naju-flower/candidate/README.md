# Naju private source

The single reviewed customer JSON is loaded directly. Markdown is review-only and is never concatenated into HTML. Four static pages, four SKU cards and three visible FAQ pairs are checked independently.

Run `npm ci`, `npm run build`, and `npm test` in candidate. This original source has no production origin or canonical and rejects release/provider environment variables. A separate release adapter will transform only generated head/control files after exact private checks. Browser/mobile, provider, public HTTP and IndexNow are separate gates.
