# Yeosu external production adapter

The frozen portable package contains the original 40 source files and 26 exact inputs. All 75 stored portable files remain byte-identical. The original package.json and private build stay unchanged.

Run this separate adapter from the frozen candidate working directory:

    node ../../../../release-adapter/scripts/build_yeosu_release.mjs

The adapter first runs the original npm build, then changes only generated HTML heads and crawler files. Full customer body bytes and the nine static assets are identical to the private preview. A production run requires an external binding, verified predecessor and successor commits, and explicit authorization. The pending control files do not authorize a release.

The existing public IndexNow proof is copied unchanged; no new key is created. Publish requires the actual reviewed runner artifact and independent bounded launch assessment. Each completed region may publish independently after its own required gates pass; stored order27 governs new-region selection only.
