# 여수 고객 원고의 사실과 출처 대응

이 파일은 원고 검토용이다. 고객에게 보이는 두 원고와 상품 카드에 조사 과정이나 미해결 운영 질문을 삽입하지 않는다. 출시는 수행하지 않았다.

## 작성 기준과 범위

- 기준 저장소 문서는 693f53f2d2f802e3cfcf0be3e3ec40efc658a32a 당시 SEARCH_CONTENT_STRATEGY.md와 SALES_COPY_ACCEPTANCE.md다. 보존된 두 파일을 직접 읽고 evidence/에 복사했다. 이번에 원격 main을 새로 조회한 것은 아니다.
- 별도 연구의 RESEARCH.ko.md, INTENT-PLAN.ko.md를 읽었다. 검색·경쟁·GitHub 재사용 조사 결과를 이번 원고의 입력으로 사용했으며 같은 조사를 새로 수행했다고 주장하지 않는다.
- 제작 범위는 지역 홈의 짧은 진입 원고, 여수전남병원장례식장 단일 구매 의도 원고, 네 상품 카드와 메타데이터다. 유캐슬·예울마루는 추가하지 않았다. 목포 26번·여수 27번의 출시 순서를 변경하지 않았다.

- 사용 위치: 상세 배송지 문단의 한 번의 주소 구분. 응급진료·진료시간을 장례식장 화환 운영시간으로 바꾸지 않았다.

### P02 실제 상품 사진

- 원본: 각 SKU의 https://fwith.co.kr/data/item/flower379/SKU/thumb-1_500x500.jpg
- 보존 원 이미지 4장을 각각 직접 열어 전체 500×500 픽셀을 검사했다. assets/의 네 사본은 원본과 SHA256이 일치한다.
- 사용 범위: 샘플 사진에서 보이는 색감·리본·위 장식의 차이만 설명했다. 꽃 수량, 높이, 생화 비율, 품질 순위, 납품 시 동일 소재·배치를 추론하지 않았다.
- 원 이미지 관찰시각은 2026-10-13이며 정확한 값은 product-cards.json 및 evidence/retained-source-provenance.json에 있다. 이번 직접 이미지 열람 시각이 원 관찰시각을 대체하지 않는다.

### P03 소재 안내 수거와 변경 상담

- assets/order-top2.jpg 전체를 직접 열어 생화·조화 혼합과 별도 화환 수거 없음의 안내를 확인했다. assets/de_change_content.jpg 전체를 직접 열어 계절·지역 소재 변화 및 교환·환불 안내를 확인했다.
- 소재·형태 변화는 원 상세/공통 안내의 보존 정책 검토를 함께 대조했다. 현장 화환 반입·설치·회수 대행을 추가하지 않았다.
- 고객 FAQ에는 혼합 사용과 별도 수거 없음만 담았다. 환불액·제작완료/출고 후 환불 결론은 제시하지 않고 현재 주문의 처리 범위를 개별 상담하는 문구로 제한했다.
- 19/21시, 주말·공휴일 적용, 환불범위에 대한 기존 미해결 질문은 새로 보내지 않았다. 그 답변이나 임의 운영시간을 원고에 넣지 않았다.

## 추정 및 편집 판단

- 예산과 사진으로 상품을 비교하는 흐름, 7만원 총예산의 예시, 차분한 조문 문구는 편집상 구매 도움이다. 실제 판매 실적이나 이용자의 감정을 확인한 사실이 아니다.
- 제공자 화자는 상품·리본·주문 상담 범위로 제한했다. 고객의 빈소 탐색·현장 반입 승인·취소 승인·정시 배송을 대신 완료한다는 뜻이 아니다.
- 한글·한자 리본의 제안은 문안 예시다. 종교·의례에 대한 보편 규칙이나 특정 시설의 의무사항이 아니다.
- 고유본문 글자수는 정보 충분성 점검용이다. 상품 카드와 출처를 제외한 값, 제목까지 제외한 순수 문장 값, 목포 대비 문자·문장 중복 결과를 따로 기록한다. 수치만으로 문체나 검색 완결성을 합격 처리하지 않는다.

## 미확인 및 출시 전 남은 확인

- 지금의 가격·재고·전화 연결·상품 상세 HTTP 응답·구매 버튼 동작, 실제 제작·배송·취소 처리는 수행하지 않았다.
- 시설의 현재 수령시간, 반입 허용·제한, 빈소, 설치·수거 처리와 현장 전달은 미확인이다.
- 승인된 여수 호스트·canonical·robots·sitemap·배포 URL이 없다. 메타데이터의 제목·설명·CTA는 고객 원고용 제안이며 실제 HTML 출력이 아니다.
- 실제 FAQ 노출, 공통 배너 3종, 이미지·CTA의 브라우저 동작, H1/H2 구조, 모바일, 404 및 공개 HTTP는 미검사다. 원고 파일의 링크·이미지 경로 존재와 SKU 대응만 로컬로 검사한다.
- 원고 작성과 그 원고의 검토를 배포·영업·검색노출 완료로 보고하지 않는다.

## 복구한 로컬 검사 오류

상품 HTML을 간단히 읽으려던 최초 Python 명령은 bs4 미설치로 ModuleNotFoundError가 났다. 새 패키지 설치 없이 표준 라이브러리의 HTML 태그 제거·행 추출로 같은 네 보존 HTML의 명칭·가격·상담번호를 직접 읽었다. 외부 원본 접근 실패나 상품 미존재를 의미하지 않는다.
