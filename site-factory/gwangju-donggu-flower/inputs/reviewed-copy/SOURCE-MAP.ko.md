# 동구 원고 근거와 확인 범위

정본 연결은 SOURCE-MAP.json의 JSON 필드, 원본 SHA, 연구 감사 digest를 사용한다. 이 문서는 고객 본문에 출력하지 않는다.

## [직접 확인]

- 공식 4상품의 보존 HTML 구매정보와 가격행, 전화, 지역 추가배송비 그룹을 직접 읽고 파싱했다. B201 59,000원 / B203 79,000원 / B205 109,000원 / B060 149,000원이다. 직접 호출을 새로 했다는 뜻은 아니며, 연구의 2026-10-15 17:16 UTC 원본을 사용했다.
- 정부 CSV 227행과 대학 시설 상세 HTML에서 시설 식별 근거를 읽었다. 전화 3352와 팩스 3353을 혼동하지 않는다. 당시 주소와 기준일을 보존했다.
- 원고 작성자가 상품사진 4장, 정책 이미지 2장, 승인 배너 3장의 실제 픽셀을 모두 열람했다. 기존 상품사진 bytes는 연구에서 별도 받은 최신 원본사진과 동일한 SHA다.
- 2026 공식 이사회 24~25쪽, 평의원회 3쪽, 학생안내 85쪽의 보존 PNG를 열람했다. 현재 운영을 확정하지 못한다는 경계를 확인했다. 현재 폐쇄라고 말하지 않는다.
- 원고 customer-copy.json과 4종 검토 Markdown, 모든 한국어 노출 문자열, 계획, 7개 자산 및 보존원본의 해시를 직접 검사했다. 실제 HTML 검사가 아니다.

## [도구 보고]

- 원래 HTTP 요청의 상태·수집시각은 연구의 보존 receipt를 읽은 것이다. 원고 작성자가 당시 네트워크 이벤트 자체를 새로 수행한 것은 아니다.
- 연구 독립감사 independent-audit.json과 원본3문서 digest를 재확인했다. 감사자 보고만으로 고객원고 독립검수를 대신하지 않는다.
- 전국 59/230 공개 계수는 기존 진행기록에 따른 값으로, 이번 원고 작업에서 59개 호스트를 검사하지 않았다.

## [추정·판단]

- 조선대병원은 정부와 대학의 식별근거를 사용한 조건부 구매상담 대상이다. 정상 운영·반입·도착 확정 판매로 표현하지 않는 범위에서만 이 초안을 제시한다.
- 리본 문구는 선택 가능한 일반 예시다. 특정 고객이 그렇게 느꼈거나 사용하는 종교·관계를 추정하지 않는다.
- 10만 원 예산에서 B201/B203 비교는 기본가만의 계산이다. 전체 결제액이나 배송비 확정이 아니다.
- 흐름·문체·소구 및 SEO 기술 구성은 편집 계획이며 실제 화면 성과·전환·검색 순위의 증거가 아니다.

## [미확인 및 실패]

- 병원 장례식장 공식 안내의 HTTP502는 접근 오류다. 휴업·폐쇄 증거가 아니며 현재 정상영업의 증거도 아니다.
- 전남대병원 공식 중단 고지는 다른 시설이다. 전남대를 활성 배송대상에서 제외했으며 금호·남도를 무리하게 늘리지 않았다.
- 동구 배송비 금액·최종 결제·재고·실제 전화연결·배송·반입·수령장소·설치·완료사진·야간/주말 접수·빈소수·현장 상태는 확인하지 않았다.
- 제작 완료 꽃상품 제외와 상품 출고 후 취소 환불 조항의 실제 적용 관계는 개별 주문 상담이 필요하다. 정책 문서의 단계를 배송완료 후로 바꾸거나 일률적인 환불을 약속하지 않는다.
- 실제 구현·공개 검증 전이다. 원고 전문 검수와 실제 HTML 검수는 별개의 미완료 게이트다.
