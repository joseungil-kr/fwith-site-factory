강남구 고객문구 독립 전문 검토 — rev2

결론: 수정 필요. 문체와 검색·정보 완결성은 별도 판정했고 두 항목 모두 수정 후 재검토가 필요하다. 지역명만 바꾼 복제는 발견하지 않았다. 이는 로컬 문구만의 판정이며 구현·공개·화면·HTTP·색인 검증은 포함하지 않는다.

1. 직접 확인 범위
근조·결혼·전시/기업행사 3글의 제목, H1, 첫 답변, 모든 본문 문단, FAQ, 출처, CTA, 관련 링크를 읽었다. 홈·목록·상품카드·설명·alt·가격/배송 안내·메뉴·디렉터리·공통공지·푸터·404·접근성 라벨도 모두 검토했다. 공통 배너 3종은 실제 이미지의 글씨를, 8상품은 실제 사진을, 주문 및 교환·환불 정책은 원본 이미지 픽셀을 열어 읽었다. 서초 rev4 두 글 전문도 직접 대조했다.

2. 먼저 고칠 사항
T01: 삼성, 그랜드힐, 코엑스, SETEC 문단에 작성자가 근거를 어떻게 해석하지 않았는지를 고객에게 설명하는 표현이 남았다. 제한을 지우라는 뜻이 아니다. 실제 고객에게 적용되는 수령/소재/반출/비용 안내를 간결히 남기고 “뜻하지는 않습니다 / 안내하지는 않습니다 / 넓히지 않으며”라는 논증을 없애야 한다. 정확한 구절과 교체안은 JSON findings에 수록했다.
C01: 세 글 모두 공식몰의 배송 완료 후 하루 이상 경과 시 교환·환불 제한을 빠뜨렸다. 원본 change-policy.jpg의 해당 행을 직접 확인했다. 제작 완료와 배송지 오류 등은 열거하면서 이 시간 제한만 빠진 상태는 주문 후 대응을 판단하기에 불완전하다. 법적 효력 판단 없이 게시정책으로 귀속하여 보완한다.
I01: 행사 FAQ는 전시/회의/예식의 차이를 본문에서 반복한다. 실제로 덜 설명된 질문으로 바꾸는 것이 필요하다. 원본 정책에서 확인되는 카드 취소 반영 시점을 묻는 대안을 제시했다.

3. 친절함·공감·스몰토크
근조의 “부고를 접하고 … 망설여질 때가 있습니다”는 독자의 현재 감정을 단정하지 않는 일반적 가능성 표현이다. 차분한 인사와 리본 상담으로 자연스럽게 연결되며 밝은 상업적 압박이 없다. 결혼은 두 사람의 축하와 친구/부서의 인사라는 상황이 구체적이고 가상 기억을 만들지 않았다. 행사는 결과를 이미 얻었다고 꾸미지 않고 전시 참가와 기업 관계에 맞는 응원의 예시를 제공한다. 홈의 질문형 한 문장은 일반적 도입으로 허용 가능하며 전 글을 같은 감성 질문으로 시작하지 않는다.

4. 판매자 화자와 확인 책임
상품·예산·리본 상담의 도움은 기존 판매자 연락/상품 주문 범위 안에 있다. 설치·완료사진·무료배송·정시도착·회수·재고·제휴·경험을 새로 보장하지 않는다. 입력 정보는 각 주문 절에 집중되어 있다. 방어적 문장 때문에 장소 절이 검토 보고서처럼 들리는 T01이 남지만, 고객에게 확인하세요를 반복해 일을 넘기는 구조는 아니다. 근조의 “도착 확약으로 받지는”은 어색하므로 N01처럼 실제 일정 상담으로 바꾸길 권한다.

5. 결혼 글의 실질 정보량
고유본문은 문단 구분 개행 포함 2,826자이며 공백 제거 2,176자다. 4종 상품가격·사진상 장식 차이·총예산 예시, 실제 그랜드힐 1/2/3층 홀, 예식시각과 희망시각, 관계에 따른 문구, 주문 입력, 혼합소재와 수거, 변경/취소를 제공한다. 따라서 분량 전체가 감성 또는 명의 설명으로 채워진 글은 아니다. 다만 문구/명의가 정리되면 상담이 간단하다는 문장과 별명/농담 단락은 효용이 낮고 더 짧게 줄일 수 있다. 목표 2,500~3,000자를 맞추려고 유지할 이유는 없다.

6. 검색 의도와 다음 행동
3개 의도의 핵심 질문은 본문에 실제 답이 존재하고 intent matrix의 인용도 본문과 일치한다. 각 상품 CTA는 SKU별 URL, 상담은 tel 번호다. 이 사실은 데이터의 연결 대상 확인이며 클릭/공개 도착 검증은 아니다. 근조의 빈소 수량 제한과 명칭 구분, 결혼의 예식 홀/회차, 행사의 반출/폐기 책임이 서로 다른 결정을 만든다. 중요한 취소 시간 제한과 행사 FAQ를 보완하면 문구 수준의 정보 완결성에 큰 공백은 남지 않는다.

서초 rev4 전문을 함께 읽었으며, 동일한 판매상품·가격·사업정책과 주문 입력은 공통 정보를 재사용한다. 강남의 삼성 진열 제한/연세 강남 관계, 그랜드힐 3개 홀, 코엑스 회의실 비용/SETEC 운영 책임은 서초의 서울성모·엘타워·aT·예술의전당 본문과 다른 실질 조건이다. 같은 지역명을 바꿔 붙인 감성 문장 묶음이나 본문 단락 복제는 확인되지 않았다. 독립 30자 ngram/최장일치/문단 비교 결과는 independent-checks.rev2.json에 있다. 수치만으로 문체 합격을 대신하지 않았다.

8. 공통 노출 문구와 이미지
홈은 8개 상품과 3개 목적 안내의 범위를 명시한다. 상품카드는 실물 사진의 보이는 색과 장식만 설명하며 더 비싸면 더 크거나 품질이 좋다는 주장을 만들지 않는다. 3배너의 메시지/예산/상담 문구와 alt가 일치하고 실제 상품사진이 아닌 AI 이미지라는 캡션이 존재한다. 예산 배너의 단일 “살펴보세요”는 반복 숙제나 훈계가 아니며 승인된 이미지 자체를 바꿀 필요가 없다. 디렉터리의 행정/법정동 설명은 주문 실적이나 배송 보장으로 과장하지 않는다. 404도 과장 없이 다음 동선을 안내한다. 실제 렌더에서 내부 metadata/renderRule이 노출되지 않는지는 아직 확인하지 않았다.
