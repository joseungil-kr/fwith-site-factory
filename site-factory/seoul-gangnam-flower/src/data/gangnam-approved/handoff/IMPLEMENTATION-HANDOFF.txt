8. 검증자료 읽는 기준
계획·원고·자산·로컬 투영 검증과 source·build·public·UI 검증은 별개입니다. 검토 verdict의 PASS가 배포나 현장 수령을 대신하지 않습니다. SHA-256은 파일 지문이며 Git commit이나 전자서명이 아닙니다. 입력 연구의 HTTP·검색·Git 관측은 보존된 보고이고 이번 원고 작성의 새 원격 검사가 아닙니다. 새 사실이나 문구를 넣거나 기존 문구를 바꾸면 원본 근거와 독립 검토·정확한 새 digest를 다시 결속합니다.
