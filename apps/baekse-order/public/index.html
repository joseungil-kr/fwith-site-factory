COM 포트 직접 출력

ESC/POS

Windows 프린터 목록에 나타나지 않는 영수증 프린터를 위한 기능입니다. 처음 연결할 때 브라우저 장치 선택창에서 실제 COM4 프린터를 선택하세요. COM 번호는 아래 설정용 이름이며 브라우저가 실제 번호를 확인하거나 강제로 지정할 수는 없습니다.

COM4 · 9600bps 설정됨. Chrome 또는 Edge에서 '장치 선택·연결'을 누르세요.

장치 선택창이 열리지 않으면 일반 Chrome/Edge 브라우저(HTTPS)로 접속하세요. 기존 POS가 COM4를 사용 중이면 포트를 동시에 열 수 없으므로 POS의 프린터 연결을 잠시 해제한 뒤 시험하세요. 한글 거래명세표는 ESC/POS 이미지 명령으로 전송되므로 프린터 모델별 호환성은 실물 시험 출력이 필요합니다. 실제 전송은 9600bps에서 다소 오래 걸릴 수 있습니다.
