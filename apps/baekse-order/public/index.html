COM 포트 직접 출력

ESC/POS

이 PC에 연결된 영수증 프린터로 바로 출력할 수 있습니다. 처음 한 번은 ‘장치 선택·연결’을 누르고, 화면에 뜨는 목록에서 프린터(COM4)를 선택하세요. 다음부터는 ‘허용된 장치 재연결’을 누르면 됩니다.

COM4 · 9600bps 설정됨. Chrome 또는 Edge에서 '장치 선택·연결'을 누르세요.

프린터 선택 목록이 나오지 않으면 이 사이트를 Chrome 또는 Edge에서 다시 열어 주세요. 프린터가 사용 중이라는 메시지가 나오면 기존 POS 프로그램의 프린터 연결을 잠시 끊고 다시 연결하세요. 오른쪽 글자가 잘리면 ‘실제 인쇄폭’을 480→448→432 순서로 줄이고 명세표를 다시 인쇄하세요. 출력 후 자동 절단을 사용할 수 있습니다.
