간이영수증 양식 작성과 무료 PDF 저장 방법

이 페이지는 물품 판매, 식자재 납품, 소규모 거래 등에서 사용할 무료 온라인 간이영수증 작성 도구입니다. 별도의 영수증 프로그램을 설치하거나 회원가입하지 않아도 브라우저에서 바로 사용할 수 있습니다. 공급자와 공급받는 자의 상호, 작성일, 품목과 금액을 한 번 입력하면 동일한 서식 두 부가 자동으로 채워집니다.

양식은 A4 세로 용지 한 장에 왼쪽 공급자 보관용과 오른쪽 공급받는 자 보관용을 나란히 배치했습니다. 보관용마다 제목 영역과 테두리 색을 달리하고 중앙 절취선을 넣어 쉽게 구분할 수 있습니다. 한 장에 최대 15개 품목을 적을 수 있습니다.

간이영수증 온라인 작성 방법

  1. 작성일과 사업자 정보: 왼쪽 양식에 작성일, 공급자(상호), 공급받는자(상호), 각 사업자등록번호, 소재지, 연락처 등을 기입합니다.
  2. 거래 품목 입력: 품목명, 규격, 수량, 단가를 최대 15행까지 입력합니다. 해당 행의 금액이 수량 × 단가로 자동 계산됩니다.
  3. 자동 복사·합계 확인: 오른쪽 공급받는 자 보관용에 입력 정보와 전체 영수금액이 자동으로 반영되는지 확인합니다.
  4. 출력 또는 PDF 무료 저장: 출력하기 / PDF 저장을 클릭합니다. 인쇄 창에서 프린터를 선택하거나 PDF로 저장을 선택하세요. A4 세로, 배율 100%, 머리글·바닥글 끄기를 권장합니다.
  5. 보관: 종이로 인쇄했다면 중앙 절취선을 따라 나눠 공급자와 공급받는 자가 각각 한 장씩 보관할 수 있습니다.

빈 간이영수증 서식을 출력하려면?

별도 품목을 입력하지 않은 상태에서 출력하기를 누르면 빈 품목 칸을 가진 양식을 인쇄할 수 있습니다. 공급자의 상호, 연락처 같은 기본 정보만 먼저 입력한 뒤 PDF로 저장하거나 종이에 출력해 두고 필요할 때 수기로 품목과 금액을 적을 수도 있습니다. 작성일 등 기본값을 비우려면 해당 입력란을 직접 지우세요.

입력값을 전체 초기화하려면 전체 초기화 버튼을 사용하세요. 입력 내용은 브라우저에서만 처리되며 자동으로 서버에 저장되지 않습니다. 작성 중 창을 닫거나 페이지를 새로고침하면 입력값이 사라질 수 있으니 필요한 서식은 인쇄 또는 PDF로 저장하는 것이 좋습니다.

간이영수증 양식의 주요 기능

15품목 자동 금액 계산

수량과 단가를 입력하면 품목별 금액 및 영수금액 합계가 계산됩니다. 합계를 따로 계산해서 적을 필요가 없습니다.

공급자용·공급받는 자용 자동 복사

왼쪽 공급자 보관용에 한 번 작성한 내용을 오른쪽 양식에 실시간으로 반영합니다. 두 부를 따로 작성하지 않아도 됩니다.

A4 세로 2부 출력

한 장의 A4 세로 용지에 2부가 인쇄됩니다. 색상과 굵은 경계선, 보관용 표기로 문서를 구분합니다.

회원가입 없는 PDF 저장

브라우저 인쇄 창의 PDF 저장 기능을 이용합니다. 회원가입과 유료 다운로드 없이 사용할 수 있습니다.

간이영수증과 세금계산서·현금영수증은 다른가요?

간이영수증은 거래한 품목과 금액, 대금 수령 사실을 적는 서식입니다. 이 간이영수증이 부가가치세법상 세금계산서나 현금영수증을 대신하는 것은 아닙니다. 비용처리나 매입세액 공제에 필요한 증빙은 거래 금액, 거래 내용과 관련 세법에 따라 달라질 수 있으므로 실제 회계처리 전 별도로 확인하세요. 본 페이지는 전자세금계산서 또는 법정 현금영수증 발급 서비스를 제공하지 않습니다.

자주 묻는 질문

간이영수증을 무료로 작성하고 PDF로 저장할 수 있나요?

네. 왼쪽 양식에 공급자·공급받는 자와 거래 품목을 입력한 다음 출력하기 / PDF 저장 버튼을 누르고 인쇄 창에서 PDF로 저장을 선택하면 됩니다. 별도 회원가입은 필요하지 않습니다.

공급자용과 공급받는 자용 영수증을 따로 입력하나요?

아닙니다. 왼쪽 공급자 보관용만 작성하면 오른쪽 공급받는 자 보관용에 같은 정보와 금액이 즉시 자동 복사됩니다.

간이영수증에 품목을 몇 개까지 입력할 수 있나요?

현재 한 장에 최대 15개 품목을 기재할 수 있습니다. 품목별 수량에 단가를 곱하여 금액을 계산하고 전체 영수금액을 자동 합산합니다.

간이영수증은 세금계산서나 현금영수증을 대신하나요?

아닙니다. 간이영수증은 거래 내역이나 대금 수령을 기록하는 일반 서식이며, 세금계산서나 현금영수증을 대신하는 적격증빙으로 항상 인정되는 것은 아닙니다. 거래 유형과 세법상 증빙 요건을 별도로 확인하세요.
