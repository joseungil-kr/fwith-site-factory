무료 업무 서식 · 사용 안내

온라인 거래명세표 작성부터 PDF 저장까지

이 페이지는 물품이나 식자재 등을 거래할 때 사용할 수 있는 무료 온라인 거래명세표 작성 도구입니다. 거래명세서 프로그램을 설치하거나 회원가입할 필요 없이 브라우저에서 바로 열어 사용할 수 있습니다. 공급자와 공급받는 자 정보를 입력하고 품목별 수량과 단가를 기재하면 계산 결과가 자동으로 표시됩니다.

양식은 A4 가로 용지 한 장에 공급자 보관용과 공급받는 자 보관용을 나란히 배치합니다. 왼쪽에만 입력해도 오른쪽 양식에 같은 내용이 자동 반영되므로 별도로 두 장을 작성할 필요가 없습니다. 중앙의 절취선을 따라 잘라 각자 한 부씩 보관할 수 있습니다.

거래명세서 작성 방법 — 5단계

  1. 거래정보 입력: 왼쪽 양식에 작성일, 명세표 번호, 공급자 상호·등록번호·주소·전화번호와 공급받는 자 정보를 입력합니다.
  2. 품목 및 단가 입력: 최대 15개 품목에 월일, 품명, 규격, 수량, 단가를 적습니다. 수량과 단가를 입력하면 해당 행의 공급가액이 자동으로 계산됩니다.
  3. 부가세 자동입력: 부가세를 더해야 하는 거래라면 왼쪽 하단의 부가세 자동입력 버튼을 클릭합니다. 10%를 계산하고 버튼명은 부가세 별도로 바뀝니다. 다시 클릭하면 원래 상태로 되돌아갑니다.
  4. 전 잔고·입금 정리: 필요할 경우 이전 미수금인 전 잔고와 이번 입금액을 입력합니다. 상단의 합계금액은 이번 거래 공급가액과 부가세 기준이고, 하단 청구합계와 잔금에는 전 잔고 및 입금액이 반영됩니다.
  5. 인쇄 또는 PDF 저장: 출력하기 / PDF 저장을 클릭한 뒤 인쇄 대상을 프린터 또는 PDF로 저장으로 선택합니다. 용지 A4, 방향 가로, 배율 100%, 머리글·바닥글 끄기를 권장합니다.

빈 거래명세표 양식 PDF와 종이 서식 활용법

입력란을 비우고 출력하시면 수기 입력용으로 사용할 수 있습니다. 빈 칸을 인쇄해 펜으로 작성하려면 빈 양식 PDF 다운로드를 누르세요. 새 창에서 기존 작성 내용을 복사하지 않은 완전한 빈 거래명세표가 열리며 PDF로 저장하거나 종이에 출력할 수 있습니다. 이 버튼은 현재 입력해 둔 자료를 지우지 않습니다.

공급처의 기본 정보만 입력하고 PDF로 저장하시거나 출력해 놓고 사용하세요. 상호, 사업자등록번호, 주소, 전화번호만 미리 작성해 빈 품목 표가 포함된 서식을 인쇄하면 반복 거래에서 편리합니다. 공급자 정보를 입력한 양식은 일반 출력하기 / PDF 저장 버튼을 이용하세요.

무료 거래명세서 양식의 특징

좌우 동일 양식 자동 완성

왼쪽 공급자용에 작성한 정보가 오른쪽 공급받는 자용에 바로 표시됩니다. 2부를 별도로 작성할 필요가 없습니다.

금액과 부가세 계산

수량 × 단가를 합산하고 필요 시 부가세 10%를 추가합니다. 전 잔고·입금액 입력에 따른 청구합계와 잔금도 확인할 수 있습니다.

무료 PDF·A4 인쇄

브라우저의 인쇄 기능으로 PDF 파일 저장 또는 A4 인쇄를 지원합니다. 별도 프로그램이나 유료 다운로드가 필요하지 않습니다.

회원가입 없는 간편 사용

작성 중인 내용은 현재 브라우저에서만 처리하며 이 양식이 서버에 내용을 저장하지 않습니다. 새로고침이나 창 닫기 전 필요한 문서를 저장하세요.

거래명세표와 세금계산서의 차이

거래명세표는 공급한 품목, 수량, 단가, 금액 등 거래 내역을 확인하는 문서입니다. 거래명세표 자체가 부가가치세법상 세금계산서나 현금영수증을 대신하지는 않습니다. 세금계산서 발급 대상 거래인 경우 별도의 적법한 증빙 발급 여부를 확인해야 합니다. 이 작성기는 세금 신고나 전자세금계산서 발행 기능을 제공하지 않습니다.

자주 묻는 질문

거래명세서 PDF를 정말 무료로 저장할 수 있나요?

네. 거래명세표를 입력한 뒤 출력하기 / PDF 저장을 누르고 인쇄 창에서 PDF로 저장을 선택하면 됩니다. 파일 저장 경로는 브라우저에서 직접 지정합니다.

아무 내용도 없는 빈 양식만 인쇄할 수 있나요?

네. 빈 양식 PDF 다운로드 버튼을 누르면 현재 입력 내용을 유지한 채 별도의 빈 서식 인쇄 창이 열립니다. 종이로 출력해서 손으로 작성해도 됩니다.

부가세 별도 버튼을 누르면 어떤 금액이 바뀌나요?

버튼을 켜면 공급가액의 10%를 세액에 더하고 상단 합계금액(부가세포함)과 하단 청구합계를 다시 계산합니다. 전 잔고와 입금액은 별도로 반영됩니다.

PDF를 저장하거나 인쇄한 후에도 작성 내용이 남나요?

현재 페이지를 열어둔 동안에는 작성 내용이 유지되지만, 새로고침하거나 창을 닫으면 사라질 수 있습니다. 필요한 문서는 출력 또는 PDF로 저장하세요.

공급자 정보만 입력한 거래명세표도 만들 수 있나요?

가능합니다. 공급자 상호와 등록번호, 연락처 등 기본 정보만 적은 뒤 출력하여 나중에 거래 품목을 손으로 기입할 수 있습니다.
